시안 A · 자막 띠

  1. 영화 자막처럼 가로로 긴 띠. 위 줄에 원문을 흐리게 한 줄, 아래에 번역을 크게 두 줄까지 보여 준다.
  2. 영상을 가장 덜 가린다. 화면 위·아래 가장자리에 붙여 두기 좋다.
  3. 아직 확정 안 된 말은 흐린 글씨로 먼저 보이고, 확정되면 하얗게 바뀐다.
  4. 두 줄을 넘으면 앞 문장이 밀려 올라가 사라진다. 지난 말은 앱 화면 기록에서 본다.

시안 B · 흐르는 말풍선 (확정)

  1. 흰 바탕 + 위에 파란 띠. 띠 오른쪽에 앱 아이콘만 작게. 상태는 글로만 알린다(소리 없음 "듣는 중…", 끊김 빨간 글).
  2. 줄마다 앞에 색 점. 말하는 사람이 바뀌면 점 색이 바뀐다(처음 나온 순서대로 파랑·주황·초록·분홍·보라). 이름표는 없다.
  3. 최근 서너 마디가 위로 흘러간다. 오래된 줄일수록 흐려지고 위쪽은 페이드로 잘린다.
  4. 말이 빠른 영상(토크·예능)에서 놓친 문장을 바로 다시 볼 수 있다.
  5. 창이 4:3이라 A보다 영상을 더 가린다. 영상 아래 댓글을 보면서 쓰기 좋다.

시안 C · 큰 글자

  1. 번역만 크게, 지금 말 한 마디만. 원문은 안 보여 준다.
  2. 창을 작게 줄여도 읽힌다. 멀리 두고 보거나 노래·방송을 틀어 둘 때.
  3. 왼쪽 위에 듣는 언어 → 번역 언어만 작게 표시한다.

앱 화면 · 화면 소리 번역

  1. 가운데 버튼이 iOS 화면 기록 시작 버튼이다. 누르면 시스템 시트가 뜨고 kemometro를 골라 시작한다. 그 동안 상태 바 시계가 빨갛게 된다.
  2. 자막 창 띄우기를 눌러 PIP를 띄운 다음 유튜브로 넘어간다. PIP는 앱이 앞에 있을 때만 시작할 수 있다.
  3. 원문·글자 크기는 PIP에 바로 반영된다. 받아 적은 말은 아래에 쌓이고, 끝나면 복사하거나 노트로 보낼 수 있다.
  4. 언어 바는 번역기 메인과 같은 모양. 듣는 언어만 고르고 결과는 늘 한국어.

iOS 제약 · 같이 정할 것

  • PIP 창은 영상이라 투명하게 못 만든다. 배경은 늘 불투명(B 는 흰색)이고, 창 안에 버튼을 둘 수 없다. 누르면 시스템이 닫기·크게·일시정지만 그려 준다. 일시정지는 번역 멈춤으로 쓴다.
  • 창 크기는 사용자가 핀치로 바꾼다. 우리는 비율만 정한다(B 4:3). 글자는 창 크기에 맞춰 다시 그린다.
  • 화면 기록은 사용자가 직접 시작해야 한다. 앱이 몰래 켤 수 없고, 넷플릭스처럼 막힌 앱 소리는 안 잡힌다.
  • 소리가 한동안 없으면 "듣는 중…"으로 바꾸고 Soniox 연결은 유지한다. 끊기면 다시 잇는 중이라고 빨간 글로 띄운다.
